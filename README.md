# 1.   相机参数、装甲板模型、坐标系、角点顺序和单位说明
## 1.1相机参数
```yaml
image_width: 1280
image_height: 1024
camera_matrix:
  rows: 3
  cols: 3
  data: [1781.053454, 0, 510.5751561,
         0, 1781.686873, 472.9735763,
         0, 0, 1]
distortion_model: plumb_bob
distortion_coefficients:
  rows: 1
  cols: 5
  data: [-0.04420740074, -0.1081537096,
         -0.0006506219039, 0.0002357380215, 0.466737247]
```



## 1.2装甲板模型
宽度为0.135m，高度为0.056m
```text
0：左上 (-w/2, -h/2, 0)
1：右上 ( w/2, -h/2, 0)
2：右下 ( w/2,  h/2, 0)
3：左下 (-w/2,  h/2, 0)
```
## 1.3坐标系
### 1.3.1世界坐标系
以装甲板几何中心为原点。X 轴平行装甲板向右，Y 轴平行装甲板向上，Z 轴垂直于装甲板向外（指向相机）
### 1.3.2相机坐标系
以相机光心为原点，X 轴向右，Y 轴向下，Z 轴指向相机正前方
### 1.3.3 2D坐标系
以图像左上角为原点，X 轴向右，Y 轴向下
## 1.4角点顺序
左上0，右上1，左下2，右下3
## 1.5单位说明
角点坐标单位为px，世界坐标系和相机坐标系的坐标 distance单位为m
# 2.测试记录和问题的分析
单独装甲板提取没有问题，但当加上计算角点并依据相关参数进行solvePnP时，视频进行一会便显示错误自动退出；我对照原视频发现自动退出的地方都属于是无装甲板灯条配对的地方，（无装甲板配对，也必然没有角点）；所以我加了一个角点存在个数为4才能继续运行的if语句

# 3.简短总结
## 3.1单帧模块怎么接入视频
利用 VideoCapture读取视频，在一个 while循环中，逐帧提取图像并对每一帧进行处理
## 3.2 solvePnP的输入与输出
### 3.2.1输入
objectPoints,imagePoints,cameraMatrix,distCoeffs
### 3.2.2输出
rvec,tvec
## 3.3位姿结果是否可靠的判断方法
利用重投影误差：先利用projectPoints函数求出重投影点，再计算各个重投影点与原本角点连线所构成向量的模长，求平均值，值较小，则可靠
